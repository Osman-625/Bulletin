# Frontend Designer

Create production-grade UI that matches Bulletin's Future Commons direction: warm, official, alive, and editorial.

## Before Editing

1. Read `AGENTS.md`.
2. Read `src/app/globals.css`.
3. Read existing components near the target.
4. Read relevant Next.js 16 docs before using framework APIs.

## Design Rules

- Use project tokens, not raw colors.
- Use Bricolage Grotesque for display, Atkinson Hyperlegible for body, and Geist Mono for metadata/code.
- Public pages should feel like a campus announcement board.
- Dashboard pages should be dense, utilitarian, and easy to scan.
- Use Lucide icons where icons are appropriate.
- Keep touch targets at least 44px.
- Do not create marketing-style hero pages unless explicitly requested.

## Review Checklist

- Text fits at mobile and desktop sizes.
- UI controls have stable dimensions.
- Contrast and focus states pass.
- Dark mode remains coherent when supported.
- Components follow local patterns instead of new styling systems.
